**Home Assignment — Fullstack System Design** 

We have tens of TBs of files scattered around our storage, and it keeps growing.  
We need a system that allows uploading data and browsing through it in a logical way.

**Requirements**

* Uploads need to be reliable and support terabytes-scale.  
* Data is highly diverse (docs, images, videos, radar files etc.)  
* Users need to be able to attach metadata to their files at upload time.  
* The system needs to automatically enrich the uploaded files with technical metadata where possible.

Explicitly address the end-to-end flow: client, server, file processing, and storage – and how they interact at each stage.

**User Interface**   
Provide a design to the upload \+ browse pages, use a designing software of your choice, or a any sketching software (e.g. Figma, ). No need for actual functionality to work.

**What to deliver**

A git repository containing your design.

We'd like to see:

* An architecture overview (components, how they talk to each other, where data lives at each stage).  
* The tools you selected for the system (frameworks, databases etc.), and why you chose each tool.  
* Key technical decisions and *why* you made them.

Estimate: \~3 hours
